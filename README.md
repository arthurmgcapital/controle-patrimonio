# Controle de Patrimônio — MG Capital

Sistema interno da MG Capital para controle de equipamentos, vendedores, estoque e logins de sistemas da equipe Athenas.

## 🌐 Acesso

[Acesse o sistema aqui](#) <!-- link do GitHub Pages aparece aqui depois -->

## ✨ Funcionalidades

- 🗺️ Mapa físico das baias com avatares dos vendedores
- 🎯 Drag & drop para mover vendedores entre baias (itens vão junto)
- 👥 Cadastro de vendedores com foto
- 📦 Controle de estoque com alertas de baixa
- 🔑 Gestão de logins de sistemas (Discadora, Storm, Outlook, etc.)
- 📊 Painel com KPIs animados
- 👑 Sistema de cargos (Admin, Supervisor, Atendente)
- 💾 Backup em Excel
- ☁️ Banco online sincronizado (Supabase)

## 🛡️ Privacidade

Os dados ficam protegidos pelo login do Supabase. Apenas usuários autorizados acessam o conteúdo.
